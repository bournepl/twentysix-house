## 1. Yu Yen / อยู่-เย็น

- Slug ที่เสนอ: `yu-yen`
- บ้านชั้นเดียวขนาดกะทัดรัด เน้นความพอดีและการใช้พื้นที่อย่างคุ้มค่า
- 2 ห้องนอน 2 ห้องน้ำ 1 ห้องนั่งเล่น 1 ห้องครัว และที่จอดรถ 2 คัน
- มูลค่าก่อสร้างที่ระบุในภาพ: 3.75 ล้านบาท
- รูปอยู่ใน `collection2 Yu  yen` จำนวน 9 ไฟล์
- รูปข้อมูลหลัก: `Yu  yen  1.webp`

## 2. Yu Plearn / อยู่-เพลิน

- 3 ห้องนอน 3 ห้องน้ำ 1 ห้องนั่งเล่น 2 ห้องครัว และที่จอดรถ 3 คัน
- มูลค่าก่อสร้างที่ระบุในภาพ: 5.94 ล้านบาท
- รูปอยู่ใน `collection1 Yu  Plearn` จำนวน 14 ไฟล์
- รูปข้อมูลหลัก: `Yu  Plearn 1.webp`

## ข้อมูลส่วนกลางของ Pure Collection

ภาพ `รวม Col PURE (1).webp` ระบุว่า Pure Collection มีบ้าน 4 แบบ และราคาเริ่มต้น 3.75 ล้านบาท ส่วนภาพ `9.webp` และ `10.webp` ให้ข้อมูลประกอบเกี่ยวกับระบบ วัสดุ การรับประกัน และบริการ เช่น:

- ระบบกรองอากาศ PM2.5 และแนวคิดบ้านหายใจได้
- ฉนวนและแนวทาง Universal Design
- การรองรับ EV
- การรับประกันโครงสร้าง 20 ปี
- บริการสำรวจ วางแผน ขออนุญาตก่อสร้าง ประสานสินเชื่อ และดูแลหลังส่งมอบ
- งานตกแต่งภายใน ระบบรักษาความปลอดภัย Solar และ Landscape ตามเงื่อนไข

ข้อความด้านระบบ บริการ และการรับประกันควรผ่านการยืนยันจากทีมอีกครั้งก่อนนำขึ้นเว็บไซต์ เพราะภาพมีหมายเหตุว่าเป็นไปตามเงื่อนไขบริษัท

## ปัญหาในหน้า Home ปัจจุบัน

ข้อมูล `catalogItems` ใน `new-home.component.ts` ยังใช้ชื่อ `Courtyard`, `Urban`, `Villa` และ `Pure` พร้อมภาพจาก `src/assets/img/Collection` ซึ่งไม่ตรงกับชื่อและรูปชุด Pure Collection ตัวจริง

ใน Phase 1 ควรสร้างข้อมูลกลางสำหรับ Yu Yen, Yu Plearn, Yu Sabai และ Yu Sook แล้วให้หน้า Home, หน้ารวม และหน้ารายละเอียดอ่านจากแหล่งเดียวกัน

## ข้อมูลที่ยังต้องยืนยัน

- ชื่อภาษาไทยและการเขียนชื่ออังกฤษอย่างเป็นทางการ
- ความหมายของไอคอนห้องครัวในภาพสรุป
- พื้นที่ใช้สอยและขนาดที่ดินขั้นต่ำของแต่ละแบบ
- มูลค่าก่อสร้างยังเป็นราคาปัจจุบันหรือไม่ และรวมรายการใดบ้าง
- เงื่อนไขระบบ บริการ และการรับประกันที่สามารถเผยแพร่ได้

## แนวทางจัดการรูปใน Phase 1

1. ใช้โฟลเดอร์ Pure Collection ชุดนี้เป็น source of truth
2. สร้างข้อมูลกลางที่อ้างอิงไฟล์เดิมก่อน เพื่อไม่ย้ายรูปโดยไม่จำเป็น
3. เลือกรูปปก รูปภายนอก รูปภายใน และรูปแปลนของแต่ละแบบให้ชัดเจน
4. ตั้งชื่อไฟล์ใหม่เฉพาะเมื่อจำเป็น และแก้ reference หลังตรวจครบทุกหน้า
5. ใช้ภาพขนาดเหมาะสมสำหรับ card และ detail เพื่อลดไฟล์ที่ผู้ใช้ต้องดาวน์โหลด

## เงื่อนไขจบ Phase 0

Phase 0 จะถือว่าเสร็จเมื่อทีมยืนยันชื่อ ข้อมูลห้อง ราคาและเงื่อนไข พร้อมแจ้งว่าพื้นที่ใช้สอยและขนาดที่ดินจะเผยแพร่หรือไม่ โดยไฟล์ข้อมูลกลางและหน้าเว็บไซต์จะไม่เติมข้อมูลที่ยังไม่มีหลักฐาน
